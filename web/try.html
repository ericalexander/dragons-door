Install itRead the chronicle

On this page, what you type and what the game sends back go to the game's narrator, an AI model from Anthropic, to tell the story. Your trial character is kept on the game's server for a week, then deleted, unless you claim it in Claude Code, when it becomes your real one. The conversation is kept for 30 days so the realm's keeper can read how trials go and improve them, then deleted. It never shows up in the rankings, the news or anywhere other players can see. To keep trials free, the site counts how many each internet address starts in a day, using a scrambled code that can't be turned back into the address. More in the privacy notes.
