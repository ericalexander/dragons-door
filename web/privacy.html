Privacy

What the game collects, why, how long it keeps it, and how to have it deleted.

The short version

Dragon's Door keeps your character and what happens to it in the game. It never sees your conversations with Claude. It doesn't sell or share anything with anyone. Ask, and your character is deleted.

What the plugin sends

The Claude Code plugin talks only to the game server at api.dragonsdoor.gg. Each call carries your character's key (stored on your own machine, in ~/.config/dragons-door/config.json), the plugin's version number, and what that action needs: a direction, a purchase, a message you wrote. Nothing else about you or your computer, and never your conversation.

Now and then the plugin reads its own latest version number from GitHub, to tell you when there's an update. That request sends nothing about you.

What the server keeps

Your character: its name, path and class, level, gold, gear, where it is on the map and where it's been, its quests, and the plugin version you last played with. Kept while the character exists.

A game log of what happens in play (fights, levels, loot, deaths), with no names and no words you wrote, so the classes can be kept balanced. Kept for as long as it's useful for balance.

What you write to other people: tavern posts (public to anyone in that town that day, and quoted in the daily news and chronicle), letters and gifts (to whoever you send them to), and Player chat in the side pane (between players only, never shown to Claude, deleted after 30 days).

What the townsfolk remember: when you talk to someone in the game, they keep a short note of what you said to them, the last few days' worth, so they remember you next time. Only your own game sees those notes.

Weather, nightfall and sign-ups

The realm's weather follows yours, and so does nightfall. To do that the server uses your rough location and time zone, from your internet address as its host reports it, looks up the sky for that area, and forgets them. Ask the narrator to turn weather off any time.

To limit fake accounts, the server counts sign-ups per internet address for a day, using a scrambled code that can't be turned back into the address.

This website

These pages count visits with Vercel Web Analytics, which uses no cookies, and with PostHog, which keeps an anonymous ID in your browser and notes which pages you read and your rough city and region from your internet address. No names, no recordings of your visit.

The trial on this website

The Try it page gives you a trial character for a day. What you type there, and what the game sends back, go to the game's narrator, an AI model from Anthropic, so it can tell the story. The server keeps the trial character for a week, then deletes it, unless you claim the character in Claude Code with its code, when it becomes an ordinary character like any other. The conversation (what you typed and what the narrator told you) is kept for 30 days so the realm's keeper can read how trials go and make them better, then deleted; after that only counts are kept (how many moves, fights and so on), with no names and nothing you wrote. Trial characters never appear in the rankings, the news, the chronicle or anywhere other players can see, and they can't write to anyone. To keep trials free, the server counts how many trials each internet address starts in a day, using a scrambled code that can't be turned back into the address; the page remembers your trial in your browser so you can pick up where you left off.

Who sees what

Other players see your character's name, class and level on the rankings, and the big moments (a level, a death, a rare find, a dragon) in the news and the chronicle on this site. The game's own maintainer can see everything the server keeps, to run the realm and deal with abuse. Posts and chat are moderated, and you can mute any player. Nothing is sold, and nothing is shared with anyone else.

The game runs on Vercel (the server and this site) and Supabase (the database). They host it; they don't use it for anything of their own.

Children

Dragon's Door is played inside Claude Code and isn't meant for children. It doesn't ask anyone's age.

Deleting your character, and questions

Write to support@dragonsdoor.gg with your character's name to have it and everything tied to it deleted, or with any question about this page. You can also open an issue on GitHub.
