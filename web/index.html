An old-school BBS Door Game, but in Claude Code.

Log in

In Claude Code, three commands:

❯/plugin marketplace add ericalexander/dragons-door
❯/plugin install dragons-door@dragons-door
❯/dragons-door:enter

Optional: a ⚔ in your Claude Code status line when there's fresh news, and a ✉ when someone's written to you.

❯/dragons-door:statusline

For the best experience, turn on auto-update so new features arrive on their own: run /plugin, open Marketplaces, pick dragons-door, and choose Enable auto-update.

Fetching the morning paper…

    Source on GitHub. Runs on a small server; the plugin is a thin client. Every rule and every roll happens server-side — the narrator only tells you what happened.

    The realm's weather follows yours. To do that it uses your rough location from your internet address, looks up the sky for that area, and forgets it. It keeps your character, your plugin version and your operating system, and nothing else about you. Ask the narrator to turn weather off any time.
